# Student Performance Analytics System

## About My Project
I have made this project using Python. It helps to check the performance of students by analyzing their marks in different subjects. I have used NumPy and Pandas to work with the student data.

## Technologies Used
- Python
- NumPy
- Pandas
- CSV File

## About the Dataset
I have created a CSV file named students.csv. It contains the details of 20 students, including their names, department, marks in Python, Maths and English, and attendance.

## Features of My Project
- It displays the student data.
- It calculates the total marks of each student.
- It calculates the average marks of each student.
- It assigns grades according to the average marks.
- It shows whether a student has passed or failed.
- It finds the highest and lowest average marks.
- It shows the name of the top-performing student.
- It calculates the average marks of each subject.
- It finds the best-performing subject.
- It counts the total number of passed and failed students.

## How to Run the Project
1. Install Python on your computer.
2. Install NumPy and Pandas using this command:

   pip install numpy pandas

3. Keep main.py and students.csv in the same folder.
4. Open the terminal in VS Code.
5. Run the following command:

   python main.py
